Rich content boundary
=====================

Dependencies: Goldmark v1.8.6 (CommonMark AST and default safe renderer),
bluemonday v1.0.27 (independent HTML tokenizer/allowlist), x/net v0.26.0
(HTML tokenization). Exact APIs were checked against downloaded upstream source
and the official Goldmark and bluemonday repositories:
https://github.com/yuin/goldmark and https://github.com/microcosm-cc/bluemonday.

Public interfaces:

- `RenderRich(source, format) -> Result[String, String]`: `legacy` and `text`
  preserve `RenderText`; `markdown` uses default CommonMark without unsafe/raw
  HTML or extensions; `html` sanitizes HTML without interpreting Markdown.
- `PlainRichText(source, format) -> Result[String, String]`: display-equivalent
  searchable text, with entity decoding, image alt text and collapsed whitespace.
- `ExtractMentionCandidates(source, format) -> Result[Slice[MentionCandidate], String]`:
  Markdown AST text only. Fields are Username, Domain, Start, End. Spans are
  original UTF-8 byte offsets, end exclusive. Non-Markdown formats return no
  candidates. Repeated occurrences remain separate until identity resolution.
- `RenderPostRich(source, format, mentions, origin, media, strict)` adds validated
  Actor links and rewrites upload URLs to post binding URLs. Original source is
  unchanged. Strict mode rejects missing local media; display mode removes stale
  references. `RichMention` contains ActorURI/Start/End; `RichMedia` contains
  UploadID/BindingID/MediaType. Storage is responsible for authorization.

Allowed HTML: p, br, hr, em, strong, ul, ol, li, h1–h6, blockquote, pre, code,
a, img. Anchors allow href/title and generated nofollow/noreferrer. Images allow
src/alt/title and an enforced no-referrer policy. URLs allow HTTP, HTTPS and
relative paths; data, javascript, vbscript, SVG/MathML elements, CSS, embedded
documents and event attributes are not allowed. External URLs are never fetched
by content. Local image references require validated raster upload metadata;
ordinary uploads use download anchors. Remote MIME validation belongs to media
handling, not to URL suffix guessing in the renderer.

Candidate grammar: ASCII letters/digits/underscore/hyphen in usernames (maximum
64 bytes); remote domains use DNS labels, including punycode, with a dot and a
253-byte maximum. Code blocks/spans, links/images and their labels/destinations,
autolinks, HTML nodes, escaped markers, encoded markers, emails and URL paths
are excluded. Input is capped at 1 MiB and candidates at 64. Server policy may
set tighter bounds. Discovery uses a single total deadline and a per-request
budget, caches duplicate attempts, refuses redirects, and reuses federation.Fetch.
Unresolved or audience-ineligible spellings remain text. Canonical URI dedup and
occurrence changes happen in the post transaction, together with media binding.

MyGO lacks Go nil comparison and interface type assertions. The two tiny AST
bridges in mentions.mygo perform only those operations; no handwritten .go
implementation is added. All zz_*.gen.go files must be regenerated by MyGO.
